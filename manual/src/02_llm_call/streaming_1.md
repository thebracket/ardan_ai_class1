# Streaming Requests

> The code is in `ex03_streaming`

Instead of sending a single request and waiting for a single reply, let's use *streaming*. We'll need some additional crates and features:

```bash
cargo add futures_util
cargo add request -F json -F stream
```

Let's do a *minimal* implementation, just enough to stream bytes back. `main` stays the same, as does much of the code:

```rust
use futures_util::StreamExt; // Needed for the stream handling trait
use serde_json::json;

async fn send_prompt(api_key: String, model: String, prompt: String) -> anyhow::Result<String> {
    let client = reqwest::Client::builder().build()?;
    const URL: &str = "https://openrouter.ai/api/v1/chat/completions";

    // We added `stream: true`
    let message = json!(
    {
        "model" : model,
        "messages" : [
            {
                "role": "user",
                "content": prompt
            }
        ],
        "reasoning": {
            "enabled": true
        },
        "stream": true
    }
    );

    let mut response = client
        .post(URL)
        .header("Content-Type", "application/json")
        .bearer_auth(api_key)
        .body(message.to_string())
        .send()
        .await?
        .bytes_stream(); // Indicate that we want a byte stream

    // Iterate through each chunk
    while let Some(item) = response.next().await {
        let chunk = item?;
        // Print it out
        println!("{chunk:?}");
    }

    // Just return a dummy value for now
    Ok(String::new())
}
```
