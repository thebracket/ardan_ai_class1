# Rust/AI Workshop

![Ardan Labs](./manual/src/ardanlabs-logo.png)

> **Work in progress.** This is the live-teaching material for the Ardan Labs
> Rust/AI workshop. The `code/` examples are further along than the `manual/`
> prose; chapters that are still being written are marked *(placeholder)* below.
> Feedback very welcome.

## Repository Layout

```text
code/
  Cargo.toml            # workspace; every exNN crate is a member
  .env                  # local only, gitignored: shared OPENROUTER_KEY
  ex01_hello/ ... ex22_mcp_server/
    Cargo.toml
    src/main.rs         # some also have src/chatbot.rs
manual/
  book.toml
  src/                  # the book source
  theme/                # Ardan Labs styling
  mermaid*.js           # vendored Mermaid runtime for mdbook-mermaid
  book/                 # generated by `mdbook build`, gitignored
```

## Getting the Code

```bash
git clone https://github.com/thebracket/ardan_ai_class1.git
cd ardan_ai_class1
```

## Viewing the Manual

```bash
cargo install mdbook mdbook-mermaid
cd manual
mdbook serve --open
```

The manual is served at <http://localhost:3000>. Diagrams are written as
[Mermaid](https://mermaid.js.org/) blocks, rendered by `mdbook-mermaid`, with the
runtime vendored in `manual/`. To build a static copy instead (written to
`manual/book/`, which is gitignored):

```bash
mdbook build manual
```
